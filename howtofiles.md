For current instructions, see [Sound packs](https://fearlessfrog.github.io/MSFS_Universal_Announcer/manual/#sound-packs) and [Set up and preview sounds](https://fearlessfrog.github.io/MSFS_Universal_Announcer/manual/#sound-files) in the user manual. This older page is kept for reference. Where it differs, follow the manual for the application version shown on its contents page.
